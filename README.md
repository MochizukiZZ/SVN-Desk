# SVN Desk

原生 macOS SVN 管理程序，使用 SwiftUI 和本机 Subversion。支持 macOS 13 及以上；本机构建产物为 Apple Silicon 版本。

## 启动

双击 `dist/SVN Desk.app`，或在项目目录运行：

```sh
open "dist/SVN Desk.app"
```

已生成的应用可以拖到“应用程序”目录。应用目前使用本地临时签名，尚未进行开发者签名与 Apple 公证；跨机器分发需要重新签名、公证。

## 功能

- 添加已有工作副本、检出新仓库，工作副本列表在本机持久保存。
- 仓库浏览器：无需检出即可浏览目录、预览文本、查看版本与作者；支持 HEAD 或指定版本、返回与上级导航、最近地址。
- 仓库直接操作：批量上传文件与新目录、覆盖同名文件、新建目录、重命名、递归删除，无需工作副本，每次操作提交一个版本。
- 显示创建时间与修改时间；预览栏默认隐藏，点击文件后展开，可关闭。
- 单文件与多选批量下载，按当前浏览版本保存原始文件，不创建工作副本；支持大文件、二进制文件及同名文件处理。
- 先浏览，再检出当前或所选目录到指定本地新目录；检出固定为浏览时的版本。
- Finder 扩展：文件与父目录 SVN 角标，右键查看差异、提交所选变更、更新、历史和仓库浏览器。
- 查看变更、可提交项、未跟踪文件、文本 / 属性 / 树冲突；支持路径搜索。
- 勾选文件提交，提交说明必填；只提交选中的路径。
- 查看彩色文本差异、未跟踪文本预览，以及最近 100 次提交与版本差异。
- 更新工作副本；添加未跟踪文件；将缺失文件登记为删除。
- 撤销本地修改、手动合并后标记冲突已解决。撤销和冲突处理均显示确认。
- 在 Finder 中定位文件，使用默认应用打开文件，查看实际 SVN 操作输出。
- 自定义 SVN 路径，保存多组登录凭据、切换默认账号，支持取消正在执行的命令。

## 使用

1. 在设置中填写凭据名称、用户名、密码，点击“保存并使用”；可保存多组凭据，下次启动自动恢复上次选择。
2. 点击左侧“仓库浏览器”，输入仓库 URL 与版本，选择“登录凭据”后点击“浏览”。
3. 双击目录进入，单击文件预览。点击“检出当前目录”或“检出所选目录”，选择登录凭据、本地父目录与新目录名称；检出成功后自动加入工作副本列表。
4. 已有项目通过“添加本地工作副本”加入；也可直接点击工具栏“检出”。
5. 选中文件查看差异；未跟踪文件通过右键菜单“加入版本控制”加入 SVN。
6. 勾选需要提交的文件，点击“提交变更”，填写说明并提交。
7. 点击“更新”同步仓库。在“提交历史”查看最近记录，选中提交查看该版本改动。
8. 冲突需要先在编辑器中完成合并，再用右键菜单“标记冲突已解决”。

快捷键：`⌘B` 仓库浏览器、`⌘O` 添加工作副本、`⌘N` 检出、`⌘R` 刷新、`⇧⌘U` 更新、`⌘K` 提交、`⌘,` 设置。

新增目录需要将待新增的父目录与子文件一起勾选。目录删除会删除整个目录。撤销目录修改会递归处理该目录；撤销新增文件只解除版本控制，不删除磁盘文件。

## 仓库浏览器直接操作

浏览 HEAD 后使用“上传”“新建目录”“重命名”“删除”，或在项目右键菜单中操作；填写提交说明后直接提交到仓库，成功后自动刷新列表。使用已选择的登录凭据，服务器仍按该账号的仓库写入权限校验。浏览指定历史版本时，写入按钮禁用。

上传可以一次选择多个文件或目录，保留空目录、递归上传目录内容；目录内忽略 `.svn`、`.DS_Store`。覆盖已有文件必须勾选“覆盖仓库中的同名文件”；同名目录不合并，符号链接暂不支持。已有文件属性在覆盖时保留，本地文件保持原位，不建立工作副本。

删除目录包含其全部子项，需要在提交窗口确认；重命名保留 SVN 历史。每批操作通过 [Subversion svnmucc](https://svnbook.red-bean.com/en/1.8/svn.advanced.working-without-a-wc.html) 提交为一个版本，以浏览时的版本为基准；目标被其它客户端修改时，过期提交会被整体拒绝，请关闭窗口并刷新后重试。取消正在执行的提交时，服务器可能已经完成提交，应刷新仓库确认实际结果后再重试。

修改时间为 SVN 条目的最近提交时间；创建时间来自该路径首次加入 SVN 的提交记录，复制或重命名后的新路径按新路径计算，不代表原始文件系统的创建时间。时间按本机时区显示。创建时间在后台最多并发 4 项查询，并按路径与最近修改版本缓存；历史权限不足等情况下显示“不可用”，提示中给出原因。

预览栏在未选择文件时隐藏；点击文件展开，点击右上角关闭按钮收起并清除当前文件选择，再次点击文件可重新展开。

顶部“刷新”或 `⌘R` 重新读取当前目录；浏览 HEAD 时读取最新版本，浏览历史版本时保留该版本。中文路径直接显示，超长地址自动换行；底部完整 URL 可横向滚动、选择复制。

选择一个文件，或按 `⌘` / `⇧` 多选文件，点击“下载”并选择本地目录；右键菜单也可下载。文件按当前浏览的固定版本保存，历史版本同样可下载，不加入工作副本列表，也不生成 `.svn`。已有同名文件时可选择“保留两份”“覆盖”或取消。批量下载逐个保存，可取消，已经完成的文件保留；失败时显示完成数量。目录下载暂不支持。

## Finder 扩展

```sh
./scripts/register-finder-extension.sh
```

在应用设置中点击“管理 Finder 扩展”，在系统设置中启用 SVN Desk Finder。扩展只监控已添加的工作副本；修改显示蓝色 M、新增显示绿色 +、未跟踪显示灰色 ?、冲突显示红色 !，缺失或待删除项目显示橙色 −；文件已删除时可通过父目录角标看到变化。干净文件不加角标，父目录汇总子项状态，冲突优先。

主程序每 5 秒查询本地 SVN 状态，扩展每 2 秒读取快照。关闭窗口后主程序继续刷新；按 `⌘Q` 退出后，快照超过 20 秒会清除角标。右键“提交所选变更”只打开提交窗口，更新也要求确认。扩展不持有密码、不执行 SVN、不连接远程仓库。

多个 Finder 扩展监控同一目录时可能争用角标。本机验证中，微信输入法与 FastZip 扩展启用时，SVN 右键菜单正常但角标不显示；临时停用这两个扩展后，修改、新增、未跟踪、冲突和父目录角标均正常显示。验证后已恢复这两个扩展。需要角标时，在系统设置中自行选择保留哪些 Finder 扩展；程序不会自动停用其它扩展。参见 [Apple Finder Sync 文档](https://developer.apple.com/documentation/FinderSync) 与 [Apple 开发者论坛的同目录扩展讨论](https://developer.apple.com/forums/thread/756711)。

状态快照位于 `~/Library/Application Support/SVN Desk/Finder/state.json`，目录权限 0700、文件权限 0600。扩展使用沙箱，只读取该状态目录；当前本地构建使用临时签名，正式分发应使用匹配的开发者签名并完成公证。

本机最终配置：按用户明确要求，微信输入法与 FastZip 的 Finder 扩展已停用，SVN Desk Finder 保持启用；两个应用的主程序保留。

## 依赖与登录

```sh
brew install subversion
```

应用自动查找 `/opt/homebrew/bin/svn`、`/usr/local/bin/svn`、`/usr/bin/svn`。也可在设置中指定其他完整路径。

在设置中管理多组凭据：“新增凭据”创建账号，“保存并使用”写入配置并设为当前选择，编辑已有凭据时密码留空会保留原密码；“删除凭据”会同时删除配置条目与钥匙串密码。设置、仓库浏览器、检出窗口共享当前选择，更新和提交也使用这组凭据；选择会持久保存。选择“使用 SVN 缓存”时，应用不传入自己的账号密码，由 SVN 使用自身缓存的认证信息。

凭据名称、用户名和默认选择通过 UserDefaults 保存在应用配置 `credentialConfiguration` 中，密码使用 [Apple Keychain Services](https://developer.apple.com/documentation/security/ksecclassgenericpassword) 保存在 macOS 登录钥匙串中；钥匙串服务名为 `net.wologic.svndesk.credentials`，条目以独立 UUID 标识。应用不导入、不改动 SVN 自身的密码缓存。钥匙串读取或写入失败会明确报错，失败时不会覆盖凭据配置。

执行 SVN 时，密码通过标准输入交给进程，不出现在命令参数或明文配置里，也不请求 SVN 缓存该密码。此方式需要 SVN 1.10 及以上支持 `--password-from-stdin`。临时签名的程序重新构建后，系统可能要求重新批准钥匙串访问，正式分发使用稳定开发者签名。

`svn+ssh` 使用本机 SSH 配置和 ssh-agent。应用采用非交互模式，不弹出终端登录提示。自签名证书和 SSH 主机信任应先在终端按自己的环境完成配置；应用不会自动信任未知证书。

SVN 工具未内嵌到应用；在其他 Mac 上使用也需要安装 Subversion。工作副本列表保存在应用的 UserDefaults，文件本身仍位于用户选择的目录。移除列表条目不会删除磁盘目录。

仓库直接写入还需要 `svnmucc`，Homebrew 的 `subversion` 包已包含该工具。程序先查找配置的 `svn` 同一目录，再查找 Homebrew 或系统路径；缺失时明确报错。`svnmucc` 同样通过标准输入接收密码，不把密码写入参数文件。

## 构建与验证

```sh
swift test
./scripts/build-app.sh
./scripts/package-app.sh --skip-build
open "dist/SVN Desk.app"
```

构建需要 Xcode 或 Command Line Tools 以及 Swift 5.9 及以上。没有远程 Swift 包依赖。`swift test` 创建独立临时仓库，验证真实检出、状态、差异、选择性提交、日志、更新冲突、解决冲突、撤销、缺失文件删除和新增目录提交；测试结束清理临时文件。未安装 `svn` / `svnadmin` 时，真实仓库测试会明确跳过。

## 当前范围

文本差异与仓库文本预览最多显示 1 MB，二进制文件由外部应用查看。历史加载最近 100 次记录，操作记录仅保留本次运行最近 100 条。分支切换、合并向导、属性编辑、锁管理和图形化三方合并尚未实现。

真实远程服务器的权限、网络、证书和 SSH 认证需要在对应环境验收。
